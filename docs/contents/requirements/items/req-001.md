# REQ-001. 회원기능(가입, 로그인, 로그아웃)

[요구사항 Home](../index.md)

## 개요

- 사용자가 서비스를 이용하기 위한 회원기능 일부(가입, 로그인, 로그아웃) 기능을 구현한다.

## 사용자 스토리

- 회원가입
  1.  사용자는 시작화면에서 회원가입 버튼을 눌러 가입 화면으로 이동한다.
  2.  사용자는 가입 정보(이메일, 비밀번호, 닉네임)를 입력한다.
  3.  사용자는 가입 버튼을 누른다.
  4.  시작화면으로 이동한다.
- 로그인
  1.  사용자는 로그인 버튼을 눌러 로그인 화면으로 이동한다.
  2.  사용자는 이메일과 비밀번호를 입력한다.
  3.  사용자는 로그인 버튼을 누른다.
  4.  서비스 메인 화면으로 이동한다.
- 로그아웃
  1.  사용자는 로그아웃 버튼을 누른다.
  2.  로그아웃 확인 알림 화면이 나온다.
  3.  사용자는 확인 버튼을 눌러 로그아웃한다.
  4.  시작화면으로 이동한다.
- 로그인 유지
  1.  사용자가 앱을 실행하거나 인증이 만료된 상태로 요청한다.
  2.  앱이 저장된 리프레시 토큰으로 새 액세스 토큰을 발급받는다.
  3.  사용자는 로그인 화면 없이 서비스를 계속 이용한다.

## 상세 요구사항

- 회원가입
  - 이메일, 비밀번호, 닉네임을 입력받아 계정을 생성한다.
  - 비밀번호는 암호화하여 저장한다.
  - 입력값 형식 검증을 한다. (이메일 형식, 비밀번호 최소 길이, 닉네임 길이 등)
  - 가입 성공 시 시작화면으로 이동한다. (자동 로그인은 하지 않음)
- 로그인
  - 이메일과 비밀번호가 일치하면 로그인에 성공한다.
  - 로그인 성공 시 인증 토큰을 발급받아 앱에 저장한다.
  - 앱을 재실행해도 로그인 상태가 유지된다.
  - 로그인 성공 시 액세스 토큰과 리프레시 토큰을 발급한다.
  - 액세스 토큰은 짧은 만료 시간, 리프레시 토큰은 긴 만료 시간을 가진다.
- 토큰 갱신
  - 액세스 토큰이 만료되면 리프레시 토큰으로 새 액세스 토큰을 발급받는다.
  - 갱신은 사용자 개입 없이 앱이 자동으로 처리한다.
  - 갱신 시 리프레시 토큰도 함께 재발급한다.
- 로그아웃
  - 확인 알림에서 확인을 누르면 앱에 저장된 인증 정보를 삭제한다.
  - 로그아웃 후에는 시작화면으로 이동한다.

## 예외 및 제약

- 이메일 또는 비밀번호가 틀리면 로그인에 실패한다.
- 이메일 중복 시 가입할 수 없고, 사용자에게 중복 안내를 한다.
- 닉네임 중복 시 가입할 수 없고, 사용자에게 중복 안내를 한다.
- 필수 입력 값이 비어 있으면 가입/로그인 버튼을 누를 수 없다.
- 리프레시 토큰이 만료되었거나 유효하지 않으면 앱의 인증 정보를 삭제하고 시작화면으로 이동한다.
