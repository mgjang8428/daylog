# REQ-001. 집중시간 기록
[요구사항 Home](../index.md)

## 개요
* 사용자는 집중시간을 기록한다.

## 사용자 스토리
* 기록 시작
    * 사용자는 기록 시작 버튼을 누른다.
* 기록 정지
    *  사용자는 기록 정지 버튼을 누른다.

## 상세 요구사항
* "시작" 버튼을 누르면 현재 시각이 시작 시간으로 기록된다.
* "정지" 버튼을 누르면 현재 시각이 종료 시간으로 기록된다.
* "정지" 버튼을 누를 시 가장 최근의 시작 시간과 조합하여 하나의 기록이 된다.
* 사용자의 집중 진행 상태는 유지되어야 한다.
* 집중 시작 시간과 경과 시간이 보여야 한다.
* 집중 중지 시 결과 화면이 보여야 한다.

## 예외 및 제약
* 사용자가 집중시간 시작 상태일 경우 중복 시작할 수 없다.
* 앱을 종료한 상태에도 진행중인 기록은 유지된다.
* 하루 시작 시간까지도 기록이 진행중일 시 그 이전 시간까지만 기록을 유지한다.
* 기록된 시간이 30초 이상일 경우만 기록이 된다.
