# PRB-001. 사용자는 하루 집중 시간을 알고 싶다
[문제정의 Home](../index.md)

## 문제
* 하루 집중 시간을 알고 싶어도 기록하기 쉽지 않음
* 월간, 주간, 일간 집중 시간 기록을 확인하기 쉽지 않다.

## 대상 사용자
* 하루 집중 시간을 측정하고 싶은 학생

## 핵심 가설
* 간편 조작만으로 집중 시간을 기록하고 확인할 수 있다면, 사용자는 꾸준히 기록하고 시간 활용 능력을 개선할 것이다.

## 성공 기준
* 사용자가 하루 집중 시간을 기록할 수단이 생긴다.
* 사용자가 집중 시간 기록을 정확히 확인할 수 있다.
* 사용자의 시간 활용 능력이 개선된다.

## 이번 MVP에서 하지 않는 것
* 관리자 기능
* 사용자 행동 통계 기능
* 정의된 기능 외 부가 및 추가 기능
