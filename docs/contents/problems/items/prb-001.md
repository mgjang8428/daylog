# PRB-001. 사용자는 서비스를 이용하기 위해 계정이 필요하다

[문제정의 Home](../index.md)

## 문제

- 사용자는 개인 데이터를 서버에 저장하고 싶다.
- 서비스가 사용자를 구분하지 못하면 사용자 별 개인 데이터를 분리하여 저장할 수 없다.

## 대상 사용자

- 서비스 이용자

## 성공 기준

- 사용자는 계정을 만들고 로그인할 수 있다.
- 사용자는 계정에서 로그아웃 할 수 있다.
- 앱을 재실행해도 로그인 상태가 유지된다.

## 이번 MVP에서 하지 않는 것

- 소셜 로그인
- 비밀번호 찾기/재설정
- 이메일 인증
- 회원 탈퇴
- 회원정보 수정
