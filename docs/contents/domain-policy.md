# 도메인 정책

[문서 Home](../index.md)

### 사용자 계정
#### 정보
* 이메일
	* 중복 불가
	* 최소 5자, 최대 254자
	* 이메일에 대문자 사용 불가
* 닉네임
	* 중복 불가
	* 최소 2자, 최대 30자
* 비밀번호
	* 최소 8자, 최대 64자
	* DB: 100
* 타임존
	* 형식: INNA 시간대 ID ex) "Asia/Seoul"
#### 정책
* 이메일은 계정 식별 정보이며, 중복될 수 없다.
* 닉네임은 중복될 수 없다.
* 비밀번호는 암호화하여 저장한다.
* 로그인 실패 시 이메일, 비밀번호 어느정보가 틀린건지 알 수 없도록 한다.

### 인증 토큰
* 액세스 토큰
	* 만료: 30분
	* API 요청 인증에 사용
* 리프레시 토큰
	* 만료: 14일
	* 액세스 토큰 갱신에 사용
* 재발급
	* 액세스 토큰 만료 시 리프레시 토큰으로 재발급 요청
#### 정책
* 로그인 / 재발행 시 accessToken과 refreshToken을 제공한다.
* 리프레시 토큰은 서버 DB에 저장한다.
* accessToken 재발급 시 refreshToken 또한 재발급 한다.
	* 기존 refreshToken은 삭제 처리한다.
* 로그아웃 시 refreshToken의 familyId를 통해 같은 familyId의 refreshToken들을 삭제 처리한다.
