# SVR-003. 회원가입

[작업목록 Home](../index.md)

## 개요

- 사용자가 서비스에 회원으로 가입한다.

## API 명세

- Method
  - POST
- URL
  - /api/v1/accounts/signup
- 인증 여부
  - 불필요

### Request

| 이름            | 타입   | 필수 | 검증                                      | 설명                            |
| --------------- | ------ | :--: | ----------------------------------------- | ------------------------------- |
| email           | String |  O   | - 이메일 형식<br>- 5~254자<br>- 공백 불가 |                                 |
| password        | String |  O   | - 공백 불가<br>- 8~64자                   |                                 |
| passwordConfirm | String |  O   | - 공백 불가<br>- 8~64자                   | 비밀번호 확인                   |
| nickname        | String |  O   | - 공백 불가<br>- 2~30자                   |                                 |
| timezone        | String |  O   | -공백 불가                                | IANA 시간대 ID (예: Asia/Seoul) |

### Response

- X

### 에러 코드

| 코드    | 상황                              | 반영 |
| ------- | --------------------------------- | :--: |
| E100001 | 이미 가입된 이메일                |  O   |
| E100002 | 이미 사용 중인 닉네임             |  O   |
| E100005 | 이메일에 대문자 포함              |  O   |
| E100006 | 존재하지 않는 timezone            |  O   |
| E100007 | password와 passwordConfirm 불일치 |  O   |
