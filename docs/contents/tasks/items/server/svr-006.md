## API 명세

- Method
  - POST
- URL
  - /api/v1/accounts/reissue
- 인증 여부
  - 불필요

### Request

| 이름         | 타입   | 필수 | 검증       | 설명 |
| ------------ | ------ | :--: | ---------- | ---- |
| refreshToken | String |  O   | - 공백불가 |      |

### Response

| 이름         | 타입   | 필수 | 설명 |
| ------------ | ------ | :--: | ---- |
| accessToken  | String |  O   |      |
| refreshToken | String |  O   |      |

### 에러 코드

| 코드    | 상황                       |
| ------- | -------------------------- |
| E100004 | 유효하지 않은 refreshToken |

- 모든 에러는 HTTP 400으로 응답한다.
