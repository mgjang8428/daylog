# SVR-004. 로그인

[작업목록 Home](../index.md)

## 개요

- 사용자가 서비스에 로그인한다.

## API 명세

- Method
  - POST
- URL
  - /api/v1/accounts/signin
- 인증 여부
  - 불필요

### Request

| 이름     | 타입   | 필수 | 검증                         | 설명          |
| -------- | ------ | :--: | ---------------------------- | ------------- |
| email    | String |  O   | - 이메일 형식<br>- 공백 불가 | 가입한 이메일 |
| password | String |  O   | - 공백 불가                  | 비밀번호      |

### Response

| 이름         | 타입   | 필수 | 설명 |
| ------------ | ------ | :--: | ---- |
| accessToken  | String |  O   |      |
| refreshToken | String |  O   |      |

### 에러 코드

| 코드    | 상황                        | 반영 |
| ------- | --------------------------- | :--: |
| E100003 | 이메일 또는 비밀번호 불일치 |  O   |

## 작업 내용

### 기능

- [x] 이메일로 계정 조회 (삭제되지 않은 계정만)
- [x] 비밀번호 일치 확인
- [x] accessToken, refreshToken 발급
- [x] refreshToken 서버 저장

### 예외처리

- [x] 이메일 또는 비밀번호가 일치하지 않음
