# APP-003. 인증상태 관리

[작업목록 Home](../index.md)

## 개요

- 로그인 인증 상태에 대한 관리

## 작업 내용

### 사용 API

- POST: /api/v1/accounts/reissue

### 에러 응답

|   API   | 코드    | 상황                            | 처리                  |
| :-----: | ------- | ------------------------------- | --------------------- |
| reissue | E100004 | 잘못된 RefreshToken으로 요청 시 | 안내 후 로그아웃 처리 |
| reissue | 401     | refreshToken 만료               | 안내 후 로그아웃 처리 |
| reissue | 403     | 권한 없음                       | 안내 후 로그아웃 처리 |
