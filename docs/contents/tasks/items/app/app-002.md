# APP-002. 가입, 로그인 화면

[작업목록 Home](../index.md)

## 개요

- 가입 페이지 생성 및 동작
- 로그인 페이지 생성 및 동작

## 작업 내용

### 사용 API

- POST: /api/v1/accounts/signup
- POST: /api/v1/accounts/signin

### 에러 응답

#### 가입

|  API   | 코드    | 상황                               | 처리           |
| :----: | ------- | ---------------------------------- | -------------- |
| signup | E100001 | 중복된 이메일 입력 시              | 가입 불가 안내 |
| signup | E100002 | 중복된 닉네임 입력 시              | 가입 불가 안내 |
| signup | E100005 | 입력된 이메일에 대문자 포함 시     | 가입 불가 안내 |
| signup | E100006 | 잘못된 타임존 입력 시              | 가입 불가 안내 |
| signup | E100007 | 비밀번호 확인이 비밀번호와 다를 시 | 가입 불가 안내 |

#### 로그인

|  API   | 코드    | 상황                           | 처리             |
| :----: | ------- | ------------------------------ | ---------------- |
| signin | E100003 | 이메일 또는 비밀번호가 틀릴 시 | 로그인 불가 안내 |

### 기능

#### 가입

- [x] 가입정보 입력 기능
- [x] 가입불가 사유 안내 (에러 처리)
- [x] 가입 요청
- [x] 가입 요청 결과 및 index 페이지로 이동

#### 로그인

- [x] Email, password 입력 기능
- [x] 로그인 실패 시 안내 (에러 처리)
- [x] 로그인 요청
- [x] 로그인 성공 시 토큰 저장 및 페이지 이동
